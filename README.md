Capstone Mini Project

Project Title: Interactive Product Inventory & Analytics Dashboard

Project Description

The capstone project is a console-based JavaScript application that manages product inventory and performs basic financial analysis.

Key Features

- Add new products using prompt-based input.
- Validate product names and prices.
- Assign product categories: Budget, Standard, and Premium.
- Search products in the inventory.
- Calculate the total inventory value.
- Apply custom tax and discount calculations.
- Filter affordable products.
- Generate formatted product reports.

How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the capstone project's "index.html" file using Live Server.
4. Enter a product name and price when prompted.
5. Open the browser Developer Tools using F12.
6. Select the Console tab to view inventory and analytics results.
